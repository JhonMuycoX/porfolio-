Library Management System

A small system for keeping track of which books are on the shelf and who has them out. It is a class project where I am learning how a web page talks to a database. It still has rough edges, and that is part of the fun.

What I worked on

  • Planned the MySQL tables for books and borrowers
  • Wrote PHP pages to add, list and update records
  • Styled the forms and tables with Bootstrap
PHP MySQL Bootstrap

Student Grade Tracker

A console program that stores a student’s scores and works out the average. I built it to practice Java classes and loops. It is small, but it taught me how to break a problem into steps.

What I worked on

  • Made a Student class that holds a name and scores
  • Wrote loops to add scores and compute the average
  • Tested with made-up scores and fixed my off-by-one mistakes
Java

Network Setup Lab

A lab where I set up a small network of computers, a switch and a router in Cisco Packet Tracer. The goal was to get every device talking to the others. Most of the learning came from working out why a ping failed.

What I worked on

  • Planned the IP addresses for each device
  • Configured the switch and the router
  • Used ping to check each connection and troubleshoot
Cisco Packet Tracer

Inventory App

A simple app for keeping track of items and how many are left. I used it to practice Python and saving data in a SQLite file. It only runs on my own computer for now.

What I worked on

  • Wrote Python functions to add, update and remove items
  • Set up a SQLite table for item names and quantities
  • Added a check that warns when stock gets low
Python SQLite
