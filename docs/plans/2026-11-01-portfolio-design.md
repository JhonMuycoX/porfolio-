# Muyco portfolio implementation plan

**Goal:** Playful personal portfolio with placeholder projects, selected by the user.
**Architecture:** Semantic HTML, responsive CSS, small optional JavaScript color switch. No framework or build step.
**Tech stack:** HTML, CSS, JavaScript.

## Design and copy deck

On this page, the five letters of MUYCO become an oversized signature, returning in the footer. The live interaction switches that signature's color palette.

Audience: potential collaborators and employers. Primary action: browse projects. Name inferred provisionally from repository; biography and role are sample copy.

Hero claim: a personal portfolio for thoughtful websites and playful digital ideas. Heading MUYCO; supporting statement “A little curiosity. A lot of making.” Action “Explore projects”.

Work: “Room for ideas.” Four original typographic placeholder title cards: Dayoff, Forma, Loop, Common Ground. Each opens a native HTML brief explaining what to replace.

About: “Curious by nature.” Editable sample biography and HTML/CSS/JavaScript focus list. No fabricated clients, testimonials, or achievements.

Contact: “Say hello.” Editable contact prompt until real contact details exist. Footer repeats the signature and offers back-to-top.

## Implementation sequence and validation

1. index.html: navigation, hero, four native details, About, Contact, footer. Check destinations and disclosure keyboard interaction.
2. styles.css: shared tokens, equal outer margins, asymmetric work wall, 600/900px responsive breakpoints, focus and reduced motion. Inspect at 390/768/1440px.
3. script.js: cycle three hero palettes, announce via live region, retain no-script fallback. Check syntax and interaction.
4. README.md: direct-open/server instructions and replacement checklist. Inspect final browser screenshots and record limits.

## Art direction

Design-taste direction: Name as a monument, seed 343782572. Type redraw: initial fashion serif conflicts with expressive studio choice. Palette redraw: initial dark gallery conflicts with chosen colorful tone; colors mapped to red/paper opening with green/blue/yellow/pink project posters. Hero redraw: no full-screen photograph exists. Work redraw to uneven wall: opposing pinned scenes exceed the minimal JavaScript request. Four purpose-built HTML/CSS placeholder title cards honor the explicit placeholder request instead of stock imagery. No external image credits required.
